==========================================================
Основа: KodBuster_ru_v2, обновлённая main 6052b7e.
Версия: ветка feature/fomo-sales-next-6052b7e.
Адрес: только на вашем компьютере, http://127.0.0.1:8765/.
Сайт kodbuster.ru, main и DNS этим предпросмотром не изменяются.

WINDOWS 10/11
1. Скачайте артефакт GitHub Actions «kodbuster-fomo-next-interactive».
2. ПОЛНОСТЬЮ распакуйте ZIP в отдельную папку (не запускайте прямо из ZIP).
3. Двойной щелчок на start-preview.bat в распакованной папке.
4. Откроется http://127.0.0.1:8765/ — листайте страницу, переключайте FOMO,
   нажимайте «Посмотреть» у тарифов, проверяйте интерактив.
5. Для остановки локального сервера закройте окно консоли (чёрное окно).

МАРШРУТЫ
Главная          http://127.0.0.1:8765/
Старт            http://127.0.0.1:8765/packages/start/
Рост             http://127.0.0.1:8765/packages/rost/
Система          http://127.0.0.1:8765/packages/sistema/
Три HTML-демо находятся в локальной папке site/demos/.
Мобильную версию можно проверить в Chrome / Edge:
F12 → Ctrl+Shift+M → размер 390×844 или 360×800.

MAC / LINUX
Из папки после распаковки:
  sh start-preview-macos-linux.sh
Откройте http://127.0.0.1:8765/.

ОГРАНИЧЕНИЯ
• Это настоящая интерактивная статическая сборка Next.js, не скриншоты.
• Отправка заявок отключена: локальный сервер отклоняет POST.
• Не вводите настоящие личные данные в формы тестовой версии.
• Ссылки на реальные внешние проекты портфолио могут открывать интернет.
• Для проверки на физическом телефоне нужен отдельный согласованный
  тестовый хостинг (сервер в ZIP намеренно доступен только локально).
• Данные демонстрационного сайта ATLAS (контакты, результаты, отзывы)
  не являются доказательствами реального клиента.
• Перед рабочим запуском нужны реквизиты оператора, production API,
  согласование контактов/Метрики, проверка отправки заявок.

Если браузер не открылся автоматически, введите:
http://127.0.0.1:8765/

Если Windows не запускает .bat, можете изучить код serve-preview.ps1
в любом редакторе. Исполняемых EXE в комплекте нет.
