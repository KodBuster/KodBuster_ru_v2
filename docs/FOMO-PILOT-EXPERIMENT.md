# KodBuster FOMO — пилот продаж (не рекламный кейс)

**Статус:** эксперимент запланирован. Данные, выигрыши, показатели конверсии пока НЕ СОБРАНЫ.

## Цель и гипотеза

Проверить, помогает ли персональная, подтверждённая открытыми источниками демонстрация недостатков цифровой презентации добиться большего числа квалифицированных обсуждений разработки сайта, чем обычная презентация агентства. Проверять также влияние на договоры и валовую прибыль.

- **Первичная метрика:** доля компаний, у которых после допустимого контакта состоялся квалифицированный разбор или предметная встреча.
- **Вторичные:** квалифицированный ответ, согласие на дальнейшую связь, отправка КП, подписанный договор, выручка, валовая прибыль, часы исследования на компанию.
- **Ограничение:** 20/20 или 25/25 компаний — пилот для выявления сигналов, не подтверждение +20% статистически. Не обещаем ROI.

## До начала

1. Сверить условия, тарифы, кейсы, реквизиты и форму с опубликованным kodbuster.ru.
2. Проверить легальность конкретного канала контакта и наличие согласий, если они требуются. **Публичный номер не равен согласию на телефонную рекламу.**
3. Подготовить 2–3 проверенных примера работ KodBuster по [шаблону доказательного кейса](./CASE-EVIDENCE-GATE.md).
4. При наличии разрешённой системы веб-аналитики проверить цели `form_start`, `audit_form_start`, `lead_submit`, `audit_request_submit` и `package_lead_submit` (метрика включается только с согласия на cookie). Передавать личные данные в Метрику запрещено.
5. Проверить реальную доставку заявок; форма без настроенного API возвращает ошибку и не должна выдавать ложное подтверждение.

## Дизайн пилота

Единица — **компания**, а не просмотры сайта. Разбить 40 компаний, у которых доступен законный сценарий коммуникации, на сопоставимые группы по нише и состоянию сайта.

- **A / стандарт:** обычное описание компании KodBuster, кейсы, тарифы, предложение обсудить проект.
- **B / диагностический:** короткий предметный анализ цифровой презентации компании, 1–2 подтверждённых различия с сопоставимыми компаниями, ссылка на новую страницу или подготовленные материалы только в рамках допустимой/согласованной коммуникации, приглашение на разбор.

Распределить случайным образом **внутри каждой ниши**. Не менять по ходу теста цены, менеджера и определения статусов без фиксации. Один контакт не должен попадать в обе группы.

## Журнал (одна строка на компанию)

| Поле | Формат |
|---|---|
| lead_id | обезличенный идентификатор |
| variant | A или B |
| niche | Детейлинг / Косметология / Ремонт / другое |
| city | населённый пункт |
| contact_basis | основание допустимой коммуникации |
| contact_date | YYYY-MM-DD |
| source_url | открытый источник для проверяемого факта |
| research_minutes | минуты на подготовку |
| content_viewed | yes / no / unknown |
| qualified_discussion | 0 / 1 |
| meeting | 0 / 1 |
| proposal | 0 / 1 |
| signed_deal | 0 / 1 |
| revenue_rub | сумма без домыслов, иначе пусто |
| gross_margin_rub | цена минус прямые затраты, иначе пусто |
| rejection_reason | точная причина по словам клиента / не известна |
| notes | кратко без избыточных персональных данных |

**Важно:** не размещать имена, личные телефоны, переписки и индивидуальные анкеты в публичном GitHub-репозитории. Контактные данные должны храниться в отдельной защищённой CRM.

## Как считать

- Доля квалифицированных обсуждений = `qualified_discussion / все компании с валидным состоявшимся контактом`; отдельно считать долю от всех назначенных компаний, чтобы не скрывать неудачные контакты.
- Доля договоров = `signed_deal / все компании в группе` с наблюдением до окончания цикла сделки.
- Стоимость дополнительной сделки учитывает исследования, дизайн аудита и работу менеджера.
- Контролировать обратные сигналы: раздражение, жалобы, просьбы прекратить контакт.

## Ревью

- **Неделя 1:** исходная воронка, QA формы, готовность доказательных кейсов.
- **Недели 2–4:** равномерное тестирование сценариев на законно доступных контактах.
- **Недели 5–8:** оценка качества встреч и предложений.
- **Недели 9–12:** накопление результатов по договорам; даже здесь небольшая выборка не доказывает причинный эффект.

## Условия решения

**Продолжать B:** если растут квалифицированные переговоры без ухудшения качества лидов, существенно большего труда и жалоб. **Доработать B:** если кликов больше, а встреч и договоров нет. **Остановить B:** если ухудшение заметно или коммуникации вызывают жалобы. Никаких заявлений о приросте продаж без достаточного массива данных.
