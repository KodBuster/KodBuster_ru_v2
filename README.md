# KodBuster — вариант №28

Отдельный поддерживаемый source-проект второй версии сайта KodBuster. Визуальная концепция: «Каждая заявка — сразу на смартфоне».

## Локальный запуск

```bash
npm ci
npm run dev
```

Сайт откроется на `http://localhost:3000`.

## Проверки

```bash
npm run typecheck
npm run lint
npm run build
```

## Структура

- `src/app/page.tsx` — содержание страницы;
- `src/app/globals.css` — визуальная система и адаптив;
- `src/data/site.ts` — услуги, кейсы, процесс и пакеты;
- `public/images/` — оптимизированные изображения;
- `tests/` — сценарии Playwright.

Проект экспортируется как статический сайт. Публикация выполняется отдельно и не включена автоматически.
